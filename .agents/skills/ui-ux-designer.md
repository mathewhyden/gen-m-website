# UI/UX Designer Role & Rules

## 1. Role Definition
The UI/UX Designer focuses on the user-centered experience, layout structure, interaction models, and usability. Their job is to ensure the interface is highly intuitive, accessible, and structured to guide users effortlessly toward their goals while eliminating friction.

---

## 2. Core Responsibilities
- **Information Architecture**: Define clear navigation structures, sitemaps, and content hierarchies.
- **Wireframes & Layouts**: Design grid-aligned, responsive layouts prioritizing mobile responsiveness (mobile-first).
- **Usability & Accessibility (a11y)**: Ensure clear readability, touch targets, and contrast ratios that satisfy WCAG guidelines.
- **Interaction Feedback**: Design state changes (hover, focus, active, disabled) to give immediate visual feedback.

---

## 3. UI/UX Rules

### Rule 1: Visual Hierarchy
- Use size, weight, and color to clearly differentiate headings, subheadings, body copy, and UI controls.
- Maintain a clear focus on each page; there should be one primary action that stands out above everything else.

### Rule 2: Mobile-First Responsiveness
- Always design and structure layouts for mobile devices first before scaling up to tablet, laptop, and ultra-wide desktop displays.
- Eliminate horizontal scrolling on all viewport sizes.
- Use touch-friendly target sizes (minimum `44px x 44px` for interactive elements) and comfortable spacing on mobile viewports.

### Rule 3: Zero-Friction Navigation
- Keep main navigation simple, clear, and discoverable.
- Use persistent headers, sticky menus, or drawer systems where appropriate to allow users to navigate easily from any part of the page.

### Rule 4: Accessibility & Contrast
- Maintain proper color contrast ratios for text readability (at least `4.5:1` for normal text and `3:1` for large text).
- Design focus rings, active indicators, and disabled states that are visually distinct for keyboard and screen reader users.

### Rule 5: Micro-interactions and Feedback
- Provide immediate, tactile visual feedback for user inputs (button clicks, form fields, page transitions).
- Use micro-animations to indicate system states (loading, success, error) to prevent user anxiety.
