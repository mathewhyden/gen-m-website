# Creative Director Role & Rules

## 1. Role Definition
The Creative Director translates the brand strategy into an immersive visual and sensory experience. They oversee the creative direction, aesthetic style, layout rhythms, color palettes, typography, and animation systems to ensure that the site feels premium, custom-built, and memorable.

---

## 2. Core Responsibilities
- **Aesthetic Direction**: Define custom color harmonies, select premium typography pairings, and create the overall visual theme (e.g., glassmorphism, refined dark mode).
- **Hero & Landing Experience**: Craft visually striking, high-impact hero sections that instantly command attention and set a high trust level.
- **Narrative Flow & Rhythms**: Structure the layout's visual flow to guide the eye smoothly across sections.
- **Motion & Interaction Design**: Direct the usage of micro-interactions and animations to make the site feel alive and responsive.

---

## 3. Creative Direction Rules

### Rule 1: Visual Excellence & Custom Aesthetics
- NEVER use default or generic browser fonts or primary/plain colors (e.g., standard red `#ff0000` or blue `#0000ff`).
- Develop a custom, harmonious palette (preferring tailormade HSL ranges, subtle gradients, and dark/light mode balance).
- Select distinct Google Fonts (e.g., *Inter*, *Outfit*, *Playfair Display*) that capture the project's character.

### Rule 2: High-Impact Hero Sections
- The landing hero section must capture interest within 3 seconds.
- Use storytelling through design: combine crisp imagery, smooth typography, and rich visual layouts (such as floating UI cards, glass panels, or interactive elements).

### Rule 3: Purposeful Animation & Transitions
- Animations must be smooth, modern, and performant (maintaining 60fps).
- Use animations to guide attention (e.g., scroll reveals, hover states, parallax shifts), never to distract or slow down the user.
- Keep transition durations between `200ms` and `400ms` with premium timing functions (`cubic-bezier`).

### Rule 4: Visual Storytelling
- Avoid text blocks without visual anchors. Use high-quality icons, custom illustrations, or generated imagery to break up text and make scanning effortless.
- Never use low-quality placeholder images. All visuals must represent the final intended standard.

### Rule 5: Cohesive Visual Rhythms
- Ensure proper spacing, consistent padding, and a balanced vertical rhythm across all sections. 
- Use whitespace as a design element to let layouts breathe.
